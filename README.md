# Sentiment Analysis Using BERT

This project develops a sentiment analysis model using BERT (Bidirectional Encoder Representations from Transformers) to classify a variety of emotions expressed in tweets. Using the SMILE Twitter dataset, which includes tweets labeled with six distinct categories—happy, not-relevant, angry, surprise, sad, and disgust—the model aims to predict the underlying sentiment of social media posts with high accuracy.

BERT’s advanced language understanding enables it to capture the nuanced expressions of emotions in Twitter posts, which often include abbreviations, informal language, and varied tones. The training process involved pre-processing the tweets, tokenizing them, and utilizing BERT's embedding layers to effectively capture the contextual information in each tweet. Fine-tuning on the SMILE dataset allowed the model to accurately distinguish between different emotions, from common ones like happiness and sadness to less frequent emotions such as disgust.

This project showcases the potential of deep learning for fine-grained sentiment analysis in social media, providing valuable insights into public emotions and trends. It can be particularly beneficial for applications in customer feedback analysis, trend detection, and understanding user engagement on social platforms.
